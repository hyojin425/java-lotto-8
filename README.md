# java-lotto-precourse

## 소개

로또 발매 프로그램입니다. 구매 금액은 1000원 단위이며 구매 금액만큼 로또를 발행할 수 있습니다.
당첨 번호화 보너스 번호를 입력하면 발행한 로또와 비교하여 등수 및 수익률을 계산하고 프로그램을 종료합니다.

## 기능 소개

### 로또 발행
- 1000원 단위로 구매 금액을 입력받아 로또를 구매할 수 있다.
- 1000원 단위가 아닌 경우 구매 금액을 다시 입력받는다.
- 1장의 로또에는 6개의 숫자가 1~45 범위로 중복되지 않게 들어간다.
- 입력 받은 구매 금액에 해당하는 만큼 로또를 발행한다.

### 당첨 번호 추첨
- 쉼표(,)로 구분된 6개의 당첨 번호를 입력받는다.
  - 1~45 사이의 수가 아닌 값이 있거나 중복되는 숫자가 있을 경우 다시 입력받는다.
  - 번호가 6개가 아닌 경우 다시 입력한다.
- 보너스 번호를 입력받는다.
  - 1~45 사이의 수가 아닌 경우 다시 입력받는다.
  - 당첨 번호와 중복되는 경우 다시 입력받는다.

### 결과 계산 및 통계
- 발행된 로또와 당첨 번호를 비교해 일치하는 개수를 계산한다.
- 당첨 개수를 계산하고 출력한다.
- 수익률을 계산하고 출력한다.


### 구현할 기능 목록

### 입력
- [x] 로또 구입 금액을 입력 받는다.
  - [x] 숫자가 아닌 경우 예외를 발생시키고 다시 입력 받는다.
  - [x] null 인 경우 예외를 발생시키도 다시 입력 받는다.
- [x] 당첨 번호 6개를 쉼표로 구분하여 입력 받는다.
  - [x] 구분자가 잘못된 경우 예외를 발생시킨다.
  - [x] null 인 경우 예외를 발생시키도 다시 입력 받는다.
- [x] 보너스 번호를 입력 받는다.
  - [x] null 인 경우 예외를 발생시키도 다시 입력 받는다.
  - [x] 숫자가 아닌 경우 예외를 발생시키고 다시 입력 받는다.

### 출력
- [ ] 로또 수량과 발행한 로또의 번호를 출력한다.
- [ ] 당첨 내역을 출력한다.
- [ ] 총 수익률을 둘째자리에 반올림하여 출력한다.

### 로또
- [x] 중복되지 않는 1~45 사이의 숫자 6개를 랜덤으로 생성한다.
- [x] 로또 번호가 6개가 아니라면 예외 처리한다.
- [x] 로또 번호가 1~45 사이의 정수가 아니라면 예외 처리한다.
- [x] 중복되는 번호가 있다면 예외 처리한다.

### 로또 발행
- [x] 구입 금액이 1000원으로 나누어 떨어지지 않는 경우 예외 처리한다.
- [x] 로또 구입 금액에 해당하는 만큼 로또를 발행한다.

### 당첨 번호
- [x] 입력 받은 당첨 번호를 검증한다.
    - [x] 모두 1~45 사이의 번호가 아닌 경우 예외 처리한다.
    - [x] 중복된 숫자가 있는 경우 예외 처리한다.
    - [x] 번호가 6개가 아닌 경우 예외 처리한다.
- [x] 입력 받은 보너스 번호를 검증한다.
    - [x] 당첨 번호와 중복되는 경우 예외처리한다.
    - [x] 1~45 사이의 번호가 아닌 경우 예외 처리한다.
- [ ] 당첨 로또 생성한다.

### 결과 계산 및 통계
- [x] 발행된 각 로또와 당첨 번호의 일치하는 번호의 수를 계산한다.
- [ ] 일치하는 수에 따라 수익을 결정한다.
- [x] 수익률을 계산한다.
